# Avito Black

Репозиторий фиксирует новый чёрный стиль презентаций Avito на основе файла `ШАБЛОН презентаци Avito.pptx`.

## Главное правило

Слайд строится как одна простая композиция на чёрном поле: крупный заголовок, много свободного пространства, один смысловой визуал и только необходимые детали. Цвет помогает читать структуру, но не заполняет весь слайд.

## Что изучено

- 95 слайдов в исходном PPTX.
- 80 рабочих чёрных макетов.
- 15 белых служебных разделителей с пометкой «Этот слайд не использовать».
- Формат 16:9, физический размер 10 × 5,625 дюйма.
- Основной шрифт: Montserrat.
- Основные цвета Avito: синий, красный, зелёный и фиолетовый на чистом чёрном фоне.
- 243 вложенных медиафайла, две нативные таблицы, ноль нативных диаграмм.

## Структура

- `brand/visual-style.md` — подробные правила визуального языка.
- `tokens/design-tokens.json` — точные цвета, размеры и координаты.
- `references/layout-catalog.md` — каталог типов слайдов и номера референсов.
- `prompts/slide-agent.md` — инструкция для создания следующих слайдов.
- `source/template-reference.md` — техническая карточка исходного шаблона.

Перед созданием новых слайдов нужно прочитать первые четыре файла. Белые служебные слайды не считаются частью визуального стиля.
