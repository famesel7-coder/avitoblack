# Инструкция для создания слайдов Avito Black

Перед работой прочитай:

1. `brand/visual-style.md`.
2. `tokens/design-tokens.json`.
3. `references/layout-catalog.md`.

## Обязательные правила

- Формат 16:9. Для изображений использовать 1920 × 1080 px.
- Фон каждого готового слайда — чистый `#000000`.
- Сохранять исходный текст дословно, если пользователь не просил редактуру.
- Основной шрифт — Montserrat.
- Стандартный заголовок: Montserrat SemiBold 24 pt, слева сверху.
- На одном слайде должен быть один главный смысловой центр.
- Использовать много свободного пространства.
- Визуал делать крупным, простым и легко считываемым.
- Фирменные цвета применять локально: `#00AAFF`, `#FF3F53`, `#00E160`, `#965EEB`.
- Маленький логотип Avito размещать справа сверху, если выбранный макет не предполагает другое положение.
- Не использовать белые служебные слайды из исходного шаблона.

## Композиция

Выбери один подходящий тип из каталога и адаптируй его под контент. Не собирай слайд из одинаковых UI-карточек. Не заполняй пустоты мелким декором. Не делай длинную цепочку стрелок, если направление не является частью смысла.

Предпочтения:

- 2–4 крупных смысловых блока;
- 1 крупная иллюстрация, фотография, схема или экран;
- короткие подписи;
- тонкие линии и контуры;
- крупные цифры;
- цветные круги или капсулы как акцент.

## Изображения

Портреты по умолчанию чёрно-белые. Предметные и абстрактные изображения должны быть простыми, без большого количества мелких деталей. Изображение не должно заходить на текст и мешать чтению.

## Данные

Графики и таблицы остаются главным объектом слайда. Убирать лишние сетки, легенды и подписи. Использовать тёмно-серые направляющие и один яркий акцент. Несколько фирменных цветов допустимы только для независимых серий.

## Финальная проверка

- весь контент сохранён;
- текст не пересекается с визуалом;
- нет переполнения и слишком мелкого шрифта;
- поля и логотип выдержаны;
- на слайде нет лишних деталей;
- композиция читается за несколько секунд;
- визуально слайд близок к референсам нужной категории.
